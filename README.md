# Market Research Intelligence Platform (MRIP)

A production-oriented multi-agent market research platform built with **Google Agent Development Kit (Google ADK)** and **Model Context Protocol (MCP)**.

## Vision

Generate trustworthy, well-structured market research reports from a simple user query using an autonomous multi-agent workflow.

## Planned Workflow

User Query

↓

Planner Agent

↓

Research Agent

↓

Verification Agent

↓

Report Agent

↓

Professional Research Report

## Tech Stack

- Google ADK
- Gemini
- MCP
- Python
- Next.js (Frontend)
